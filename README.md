# ZPE — Zero-Point Energy

Hyper-minimalist dark-mode landing page for [zpe.vc](https://zpe.vc).

## Tech Stack

- **React** + TypeScript
- **Vite** for build
- **Cloudflare Workers** for hosting

## Development

```sh
npm install
npm run dev
```

## Deploy

Connected to Cloudflare via GitHub integration. Push to `main` triggers auto-deploy to `zpe.vc`.
